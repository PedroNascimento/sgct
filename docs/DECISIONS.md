## Como usar este log
Ao escrever um `plan.md` para qualquer spec, cite o(s) ID(s) de decisão relevante(s) na seção "Decisões Técnicas Resolvidas" em vez de reexplicar o raciocínio. Se uma decisão precisar mudar, registre a mudança aqui **e** avalie se algum `plan.md`/`spec.md` existente precisa ser revisado (mesma disciplina de governança do Artigo IX da constituição, mas para decisões de produto em vez de princípios de engenharia).
